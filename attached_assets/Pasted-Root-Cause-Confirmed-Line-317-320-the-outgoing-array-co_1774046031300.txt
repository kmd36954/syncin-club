Root Cause Confirmed
Line 317–320 — the outgoing array contains your interest requests TO other rides. The Journey Offers tab is showing these — but it should show available rides from other members (which are never fetched at all).
The tab labels are also swapped conceptually:

"Journey Requests" tab (incoming) = people requesting to join YOUR ride ✅
"Journey Offers" tab (outgoing) = YOUR requests to join others ❌ — this is wrongly named AND the badge counts cancelled/dismissed ones

The badge count bug — line 214:
js...outgoing.filter(i => i.status !== "pending"...) // counts dismissed + cancelled = inflated number
