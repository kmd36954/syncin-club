PROJECT: Synicin Club (Private Verified Professional Network)

OBJECTIVE:
Convert the current app into a PREMIUM, MEMBERS-ONLY professional journey-sharing platform.
This is NOT a ride-hailing app. Remove all taxi-like behavior.

---

## CORE EXPERIENCE GOAL

The app must feel:

* Exclusive
* Trust-based
* Professional
* Minimal and premium

Users should feel:
“I am entering a private verified network, not a public app.”

---

## STEP 1: LANDING / GATEKEEPING SCREEN (MANDATORY)

Create a new first screen BEFORE app access.

Content:

Title:
"Synicin Club"

Subtitle:
"A Private Network for Verified Professionals"

Description:
"Access is restricted to professionals with verified identity and credentials."

Buttons:

1. "Apply for Membership"
2. "Member Login"

Add small footer text:
"Travel with people you can trust"

Block access to dashboard unless user is approved.

---

## STEP 2: ONBOARDING (MAKE IT PREMIUM)

Replace simple forms with a structured “Membership Application”

Fields:

* Full Name (required)
* Designation (required, dropdown + custom input)
* Organization / Company (required)
* LinkedIn Profile URL (required, validate format)
* Phone Number (OTP verification required)
* CNIC Upload (required)
* Profile Photo (selfie upload required)
* Short Answer:
  "Why do you want to join Synicin Club?"

If user selects “Host” role, add:

* Car Model
* Registration Number
* Car Registration Document Upload

After submission:
Show screen:
"Your application is under review"

Add user status system:
